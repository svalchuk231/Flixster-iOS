# Flixster

**Flixster** is an iOS movie browsing app built with Swift. Flixster fetches currently playing movies from The Movie Database (TMDB) API and displays posters, descriptions, and movie details. 

By: **Snezhana Valtchouk**

## Features:
- [x] Fetch currently playing movies from the TMDB API and display titles, descriptions, and posters in a table view.
- [x] Display the same movies in a collection view.
- [x] Use a tab bar controller to switch between the table view and collection view.
- [x] Select a movie to view additional details.
- [x] Background colors

## Technologies:
- [x] Swift
- [x] UIKit and Storyboards
- [x] URLSession
- [x] Decodable and JSONDecoder
